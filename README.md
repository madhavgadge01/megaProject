# Simple Blog App — 

A small full-stack practice project featuring user authentication and basic blogging features.  
Users can **log in, log out, add posts, edit posts, and view posts created by other users**.  
Built using **Appwrite** for backend (Auth + Database).

---

## 🚀 Features
- User Login & Logout  
- Add New Post  
- Edit Existing Post  
- View Posts from All Users  
- Appwrite Database Integration  
- Full Frontend + Backend

---

## 🛠️ Tech Stack
- **Frontend:** React / Vite (or your setup)    
- **Database & Auth:** Appwrite
